# Security Policy

## Supported versions

Only the latest published release is supported with security fixes. Upgrade to
the latest version from [PyPI](https://pypi.org/project/gha-cache-auditor/).

## Reporting a vulnerability

Please report suspected vulnerabilities privately through
[GitHub's private vulnerability reporting](https://github.com/0then0/gha-cache-audit/security/advisories/new)
when it is available for this repository. Do not open a public issue with
unfixed vulnerability details.

If private vulnerability reporting is unavailable, contact the maintainer
through the contact methods on the [project's GitHub profile](https://github.com/0then0).
Include the affected version, a concise impact description, and safe
reproduction steps. Remove credentials, tokens, and private workflow data from
examples.
